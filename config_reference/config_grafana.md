#🚀 How to Use
Save the JSON file (springboot-dashboard.json) locally.

In Grafana → Dashboards → Import → Upload JSON file.

Select your Prometheus datasource.

You’ll see panels for JVM memory, CPU, GC, threads, and request latency.
